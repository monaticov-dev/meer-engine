# Minecraft 1.7.10 — реальный клиент + реальный сервер (portable, два процесса)

Это настоящая Minecraft 1.7.10 (клиент и сервер Mojang, официально скачанные, SHA1
сверены) в portable-упаковке. Архитектура «только сервер-клиент»: синглплеера нет,
всегда запускается серверный процесс, к нему подключается клиент.

## Запуск
1. `start-server.cmd` — поднимает сервер (порт 25565, world в `data\world`).
2. `start-client.cmd` — клиент стартует и **сам подключается** к `127.0.0.1:25565`.
   (Хочешь играть с другого ПК/через интернет — правь `--server` в start-client.cmd
   на внешний IP сервера и пробрось порт.)

## Что внутри
- `app\` — client-1.7.10.jar, server-1.7.10.jar (piston-meta, SHA1 ✓)
- `libs\`, `natives\` — библиотеки и Windows-natives
- `jre\` — своя Java 27 (Temurin), ничего ставить не нужно
- `assets\` — звуки/музыка 1.7.10 (Mojang CDN)
- `data\` — мир, конфиги, логи. Всё только здесь.

## Конфиги
- `server.properties` — порт 25565, online-mode=false (оффлайн-режим), motd.
- eula уже принята.

## Ограничение
Это референс-пара (настоящий код Mojang) — рабочее подспорье, пока наш собственный
движок (MEER) дособирается до полного замещения. Личное использование, без распространения.
