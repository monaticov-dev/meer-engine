# EXTREME_ROADMAP

Каждый этап = рабочая сборка + метрики до/после + тест корректности + откат. Регрессия → разбор → откат.

## Фазы-предвестники (текущие)
- **A. Аудит/консолидация** — факты артефактов, лицензии, хеши, git. → DEPENDENCIES/AUDIT готовы.
- **B. GT-реестры** — GT_REGISTRY (полная инвентаризация канона+аддонов, пиннинг D-003), GT_MATRIX (матрица соответствия, честные проценты), дельта GT5u-vs-5.07.07.
- **C. Benchmark-каркас** — фиксированный seed, scripted-сцены, полный набор метрик §6, JFR; baseline до оптимизаций.

## S0 Fork runnable (M0)
Remap (fml.srg+deobf-data+csv → SpecialSource) → Vineflower → game-src; свой bootstrap; клиент-референс и сервер запускаются на JDK 27; baseline-метрики.

## S1 Собственный клиент + сервер + протокол v1 (M1)
src/client с нуля (окно/GLFW, ввод, рендер-минимум, UI-минимум), src/server (симуляция из game-src ядра), свой протокол (framing/versioning/AOI/дельты/квантование/backpressure), «Играть» = сервер-процесс+connect, интернет-режим (bind 0.0.0.0/UPnP/public-ip консоль). Клиент без симуляции (linkage-check).

## S2 Мир/чанки/свет (M2)
Async chunk-engine (gen/load/save), packed palettes, dirty regions, event-driven, BFS-дельта свет, CPU-бюджеты по подсистемам, детерминированность (seed).

## S3 Рендер (M3)
HW-probe → GL-путь (modern core + compat-фолбэк по факту драйвера), VBO/persistent mapping, батчинг, multithreaded meshing, frustum+occlusion culling, state sort, атласы. Метрики: FPS/1%low/draw calls.

## S4 Эффекты/звук/ресурсы (M4)
Частицы пулы+LOD+culling, async audio, ресурс-индекс/дедуп/ленивость.

## S5 Сеть v2 + MP-стресс (M5)
Батчи сущностей, квантование-тюнинг, 2+ клиента, деградация при лагах, «злой клиент».

## S6 GT волны (M6 после каждой)
Порядок: материалы/руды/жилы → LV-ядро (рудная цепочка) → энергосеть → MV/HV → жидкости/газы → мультиблоки → тепло/давление/взрывы → аддоны по реестру. Каждая волна: срез GT_REGISTRY → собственная реализация → GT_MATRIX обновление → бенчмарки. GTNH-ideas помечаются отдельно (D-004).

## S7 Storage (M7)
Свой формат (packed+compress+CRC), Anvil-импорт read, тесты целостности.

## S8 java-runtime (M8)
jdeps → jlink (минимум модулей), AOT cache vs AppCDS — измерить оба, GC-выбор по метрикам (Serial/G1/ZGC), ≤60 МБ, старт-метрика.

## S9/S10 Верификация + portable (M9/M10)
Полные метрики §6, стресс сущностей/эффектов, кириллица/пробелы/флешка, офлайн-аудит, BUILD_REPORT + zip.

## Отступления от порядка
Разрешены при техобосновании в DECISIONS; S0→S1 — критический путь, всё остальное параллелится.
