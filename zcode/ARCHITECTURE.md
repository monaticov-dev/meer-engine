# ARCHITECTURE (целевая)

## Два процесса
```
┌────────────── SERVER (авторитет) ──────────────┐   ┌──────── CLIENT (терминал) ────────┐
│ bootstrap   запуск, пути, конфиг               │   │ bootstrap  запуск, авто-сервер    │
│ world       ген/загрузка/сохранение чанков     │   │ net        свой протокол, AOI     │
│ chunk-eng   async gen/load/mesh-подготовка     │   │ renderer   свой GL backend        │
│ lighting    BFS-дельта, worker pool            │   │ resources  индекс/дедуп/атласы    │
│ physics     AABB, spatial index, жидкости      │   │ input      клавиши/мышь/тачпад    │
│ entities/AI тик-бюджеты, pathfinding           │   │ audio      async, spatial         │
│ redstone/fl Бюджетированные апдейты            │   │ effects    частицы пулы+LOD       │
│ gt          GT-ядро: машины/энергия/мультиблоки│   │ ui         GUI/GT-GUI/чат/настройки│
│ storage     свой формат + Anvil-импорт         │   │ interp     предикция/сглаживание  │
│ net         протокол, AOI, дельты, backpressure│◄──►│            (только отображение)   │
│ profiling   JFR, счётчики                      │   │ profiling  JFR, счётчики          │
└────────────────────────────────────────────────┘   └───────────────────────────────────┘
        ИНТЕРНЕТ: bind 0.0.0.0, UPnP/PCP-проброс, печать IP:порт в консоль (D-006)
```
Клиент НЕ содержит: мир/блоки/физика/сущности/AI/редстоун/жидкости/машины/рецепты/энергетика — только снапшоты сервера + визуальное предсказание.

## Протокол (свой)
- Транспорт: TCP, framed binary, byte-order фикс (LE), versioning в handshake.
- Контент: delta snapshots, AOI (interest management), квантование координат/нормалей, батчинг сущностей.
- Устойчивость: backpressure, лимиты очередей, валидация пакетов (мусор = disconnect), контроль порядка, CRC/длина.
- Тесты: рассинхрон, обрывы, нагрузка (N клиентов), «злой клиент».

## Модули кода
`src/shared` (протокол-типы, мат. примитивы, ID-реестры) · `src/server` · `src/client` · `src/gt` (industrial-engine, сервер+GUI-схемы) · `src/bootstrap` · `src/compat` (GL-абстракция, HW-probe, D-012).

## Данные
- Миры: свой формат (packed palettes + компрессия + CRC) + Anvil-импорт (read) для старых миров (S7).
- Конфиг/кэш/логи/ассеты-оверрайд: строго внутри папки сборки.

## Behaviour oracle
Деобф-исходники 1.7.10+Forge (game-src) — эталон соответствия для всех переписанных подсистем; не запускается в финальном продукте как клиент-архитектура, используется как reference и тест-коридор.
