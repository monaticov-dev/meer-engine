# RISKS

## Технические
| Риск | Вероятность | Урон | Митигция |
|---|---|---|---|
| Тег GT5u 5.09.31 не существует (выбран 5.09.33.02) | факт | расхождение с пином пользователя | D-003 задокументирован; вето пользователя |
| Декомпил-искажения (Vineflower на JIT-паттернах 2013 г.) | средняя | сломанный game-src | компиляция каждого пакета; тесты; сравнение со static-merged.jar |
| Свой GL backend на iGPU Radeon — неполный GL 4.6/др. баги | средняя | фолбэк-путь | HW-probe + compat-путь; проверка на железе, не по названию |
| Свой протокол: рассинхроны/баги порядка | высокая (ранние итерации) | сломанный MP | детерминированный seed, тесты рассинхрона, валидация пакетов |
| GT 1:1 масштаб (тысячи позиций) | факт | «почти сделано» самообман | GT_MATRIX с честными статусами; волны; непроверенное = непроверенное |
| Pack200 убран из JDK → сборочные утилиты держат JDK 8 | факт | сборочный долг | runtime/jdk21 + системный JDK8 только для StaticPatcher; фикс-таймстампы для детерминизма |

## Производительность
| Риск | Митигция |
|---|---|
| Оптимизация «на веру» | каждый патч: до/после на benchmark-сценах; откат при регрессии |
| iGPU + общая память: bandwidth-узкое место | атласы/батчи/меньше CPU→GPU копий; замеры draw calls |
| GC-паузы на 16GB shared | профиль GC под нагрузкой (Serial/G1/ZGC) по метрикам, не по моде |

## Юридические
| Риск | Статус | Митигция |
|---|---|---|
| LGPL-код GT5u/FML в едином jar | запрет по спеке | код не копируется; механики переосмысляются; источник каждой механики в GT_REGISTRY |
| Ассеты GT (текстуры/звуки) | запрет без прав | свои ассеты + папка оригиналов пользователя; ASSET_LEDGER |
| Лицензии Minecraft/Forge артефактов | проверка фактов в Phase A | DEPENDENCIES.md: лицензия+происхождение каждого артефакта; личное использование, без распространения |
| GTNH-контент просочился в канон | средний | метка происхождения в реестре; аудит реестра |

Все «предположения» в этом файле не считать проверенными фактами до проставления проверки.
