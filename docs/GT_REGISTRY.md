# GT_REGISTRY — реестр канона GregTech (спека §14)

Канон: GT 5.07.07 (первоисточник) ⊆ GT5u 5.09.31-снапшот (tag 5.09.33.02, commit 77a3c956).
Метод: инвентаризация из исходников снапшота (источник каждой позиции — класс/конфиг/рецепт-код),
доп. сверка с GT5 wiki. Дельта GT5u-vs-5.07.07 — отдельный раздел (заполняется после прогона
двух списков). Классификация происхождения: [GT5] оригинал / [GT5u] добавлено GT5u /
[Addon] аддон / [GTNH-idea] идеи (не контент!). Статус: INV (инвентаризировано) → IMPL (реализовано
у нас) → VER (проверено матрицей). Непроверенное = непроверенное.

## Источник фактуры (скан 2026-11-10, снапшот 77a3c956)
- src/main/java/gregtech/common/tileentities: 111 позиций пути (machines 83, из них multi 45, basic 19)
- api/enums: Materials.java, OrePrefixes.java, ItemList.java, Tier.java (LV–UV), Dyes, Element, TextureSet
- worldgen: GT_Worldgen_GT_Ore_Layer (слой-жилы), GT_Worldgen_GT_Ore_SmallPieces (мелкие руды), GT_Worldgen_Stone, GT_UndergroundOil, GT_Pollution, GT_Worldgenerator
- api/metatileentity/implementations: 27 файлов (базовые MetaTileEntity)
- Точный подсчёт .java и полный список классов — волна сканирования #2 (см. WORK_LOG)

## Разделы (каждый — отдельная волна инвентаризации; НЕ выдумывать, только из источника)
1. Машины простые/сложные (basic machines, steam, генераторы)
2. Мультиблоки (структуры, требования, режимы)
3. Материалы (полный список Materials + свойства: температура плавления, прочность, цвета)
4. Руды/жилы (ore layers: состав, высоты, веса; small ores)
5. Рецепты (RecipeMap'ы: входы/выходы/длительности/энергия) — предметный реестр цепочек
6. Напряжения/энергетика (LV–UV, потери, хранение)
7. Жидкости/газы
8. Побочные продукты/отходы
9. Спец-механики (перегрев/давление/взрывы, режимы машин, конфиг-влияющие на геймплей параметры)
10. Аддоны-реестр (TecTech, BartWorks, GT++, GoodGenerator и весь скан экосистемы; происхождение/версии/зависимости/лицензии/статусы)
