# GT_MATRIX — матрица соответствия 1:1 (спека §14)

Правило: 100% = только подтверждённое. Непроверенное = непроверенное. Отсутствующее = отсутствующее.
Каждая позиция: канон-источник (класс/версия) → оригинальное поведение → что реализовано → проверки →
что отсутствует → вердикт.

## Статус по категориям (обновляется после каждой волны S6)
| Категория | Позиций в каноне (INV) | IMPL | VER | % (честный) |
|---|---|---|---|---|
| Материалы | скан #2 | 0 | 0 | 0% |
| Машины basic/steam | скан #2 | 0 | 0 | 0% |

| Спец-механики | скан #2 | 0 | 0 | 0% |
| Аддоны | реестр волны #2 | 0 | 0 | 0% |

## Формат строки матрицы (расширяется по ходу волн)
```
| ID | Канон: источник/класс | Поведение | Реализация (модуль/класс) | Проверка (тест/сценарий) | Отсутствует | Вердикт |
```
Ни одна строка не помечается VER без исполняемой проверки (тест/сценарий в tests/ или benchmark-сцена).
